# FABIJAN D. SVETAC — AUTHOR HOTSITE

This is a static one-page author website designed for the Goodreads Author Program
and the Project Aurora 371 launch.

## BEFORE PUBLISHING
1. Open index.html.
2. Replace every occurrence of AUTHOR_EMAIL_HERE with the official author email.
3. Confirm the Amazon link is the desired marketplace URL.
4. Optional: replace the cover placeholder with the final book-cover image.

## IMPORTANT FOR GOODREADS
The contact email must be the official author email and should be the same email
associated with the Goodreads account, as required by the Goodreads Author Program.

The site intentionally contains no real-name biography, profession, location,
LinkedIn, or other information that could connect Fabijan D. Svetac to the author's
private identity.

## PUBLISHING
This site can be hosted on any static hosting service (for example GitHub Pages,
Cloudflare Pages, Netlify, or similar). No server/database is required.
